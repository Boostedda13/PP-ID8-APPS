# PP-ID8-APPS

Add `Boostedda13/PP-ID8-APPS` manually as a GitHub source in MGU Store. Follow
`main` or select **Tags** to track numbered versions. Choose **PP DATA** to
install the iDrive 8 app. The app uses the MGU renderer for its dashboard and
page navigation.

PP DATA has Engine, Fuel & Air, Transmission, Details, Fault Codes, and
Settings pages. Engine shows live readings and supplies a gear fallback for
recognized ZF 8HP variants. Fuel & Air shows live fuel flow and samples its
charts while the tab is open. Fault Codes runs a manual scan and displays the
last saved count. Clearing requires confirmation and a stationary vehicle
with the engine off. The compact Settings panel sits at the lower left and
offers Metric or SAE units, gauge maxima, and optional warning and alarm
thresholds.

Enable **MHD strip** in Settings to show one-tap Map, Exhaust and Max Cooling
controls above the Engine gauges. The strip defaults to off and requires a
compatible MHD tune. A highlighted button shows the last command acknowledged
by the engine controller. Max Cooling On requires a fresh reading above 500 rpm.

The catalog carries the app's source archive. The Store links it
against the head unit's OAP SDK during installation.
