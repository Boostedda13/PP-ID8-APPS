# PP-ID8-APPS

Add `Boostedda13/PP-ID8-APPS` as a GitHub source in MGU Store and select the
**Tags** channel. Choose **PP DATA** to install the iDrive 8 Engine page.

PP DATA reads engine speed, torque, boost, vehicle speed, temperatures and
supply voltage through the head unit's SDK. It derives power from engine
speed and torque. Fields the vehicle does not report show `--`.

The tagged catalog carries the app's source archive. The Store links it
against the head unit's OAP SDK during installation.
