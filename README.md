# PP-ID8-APPS

Add `Boostedda13/PP-ID8-APPS` as a GitHub source in MGU Store and select the
**Tags** channel. Choose **PP DATA** to install the iDrive 8 app. The MGU
renderer supplies the dashboard and page navigation.

PP DATA has Engine, Fuel & Air, Trips, Transmission, Details, and Settings
pages. Vbatt shows the head unit's supply voltage. Engine and Fuel & Air
show how much warmer the intake air is than outside. Fields the vehicle
does not report show `--`.

The tagged catalog carries the app's source archive. The Store links it
against the head unit's OAP SDK during installation.
